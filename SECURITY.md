# Security policy

## Reporting a vulnerability

Email security issues to [thewwwnash@gmail.com](mailto:thewwwnash@gmail.com) with "Refuge Presenter security" in the subject. Don't open a public issue, pull request, or discussion for them.

Include what you can of the following:

- The affected component (desktop app, website, or a shared package) and version or commit
- Steps to reproduce, or a proof of concept
- The impact you expect, such as code execution, data exposure, or loss of a running presentation

You'll get an acknowledgment within 7 days. Once a fix is ready, we publish a security advisory and credit you unless you ask not to be named.

## Supported versions

Refuge Presenter is in early development. Only the latest commit on `main` receives security fixes.
